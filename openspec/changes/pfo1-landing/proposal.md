## Why

Crear la entrega individual PFO1 de la materia Desarrollo de Sistemas Web · Front End (4to semestre, 2026): una landing estática de portafolio personal que presente mi perfil, habilidades reales y un formulario de contacto. El objetivo es cumplir y superar la rúbrica de evaluación con HTML semántico, CSS propio, Flexbox + Grid, animaciones propias, responsive design y documentación honesta del uso de IA.

## What Changes

- Se agrega el change `pfo1-landing` bajo el esquema `spec-driven`.
- Se crea la landing como página única estática: `index.html` + `styles.css`.
- Se reutiliza la marca `ev_` del portfolio anterior (navy base, acento oro, texto slate, favicon cursor `ev_`).
- Se incluye sección personal "Mi camino de aprendizaje" con timeline 2021→2026.
- Se documenta el proceso en `README.md` con declaración de uso de IA completa.
- Se despliega en Vercel como sitio estático sin build step.

## Capabilities

### New Capabilities
- `pfo1-portfolio`: landing estática de portafolio personal con estructura semántica, estilos `ev_`, animaciones y formulario de contacto.

### Modified Capabilities
- Ninguna. Este es un proyecto nuevo.

## Impact

- Nuevos archivos en la raíz del repo: `index.html`, `styles.css`, `README.md`.
- Nuevos archivos de trazabilidad bajo `openspec/changes/pfo1-landing/` y `openspec/specs/pfo1-portfolio/`.
