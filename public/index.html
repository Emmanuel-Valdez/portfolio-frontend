Sobre mí

Programo desde 2021. Empecé con Java de forma autodidacta, seguí con desarrollo web full stack (Node.js, React) y hoy mi foco está en el backend con C# y ASP.NET Core. Curso la Tecnicatura Superior en Desarrollo de Software en el IFTS N° 29.

Antes pasé por la Tecnicatura en Producción Industrial y Automatización (ITU UNCuyo): ahí aprendí a analizar procesos y resolver problemas técnicos con criterio de sistema, algo que uso todos los días cuando diseño software.

No me vendo como senior: construyo proyectos reales de base de datos a despliegue y muestro el camino. Esta landing es la PFO1 de Front End; la armé con HTML y CSS propios, iterando con agentes de IA y revisando cada decisión con mi criterio.
